# BSP Manual Configuration Tutorial

This document explains the current board configuration model in NexusRTOS.

Audience:
- New contributors onboarding a board
- Developers updating memory maps, linker regions, or IRQ policy
- Anyone migrating from the old configure_file-based flow

## 1. Current approach

Board configuration is now maintained directly in board files under:

- bsp/<board>/config/memory_map.h
- bsp/<board>/config/linker_unified.ld
- bsp/<board>/config/board_irq_map.h
- bsp/<board>/config/board_irq_table.c

No BSP config artifacts are generated by CMake for this flow.

## 2. Data flow

```text
bsp/<board>/config/<board>.cmake
  ├─ sets NEXUS_BOARD_LINKER_SCRIPT -> linker_unified.ld
  └─ sets NEXUS_BOARD_INCLUDE_DIRS  -> includes bsp/<board>/config

bsp/<board>/CMakeLists.txt
  └─ compiles config/board_irq_table.c into board secure module

bsp/<board>/inc
  └─ private board headers (for board implementation files only)

board.h
  └─ includes board_irq_map.h

board_early_init.c
  └─ iterates nexus_board_irq_table[]
```

## 3. Board entry CMake example

Example pattern for bsp/<board>/config/<board>.cmake:

```cmake
set(NEXUS_BOARD_ARCH "arm")
set(NEXUS_BOARD_CPU "cortex-m33")

set(NEXUS_BOARD_CPU_FLAGS
    -mcpu=cortex-m33
    -mthumb
)

set(NEXUS_BOARD_LINKER_SCRIPT "${CMAKE_CURRENT_LIST_DIR}/linker_unified.ld")

set(NEXUS_BOARD_INCLUDE_DIRS
    ${CMAKE_SOURCE_DIR}/bsp/common/include
    ${CMAKE_SOURCE_DIR}/bsp/<board>/include
    ${CMAKE_CURRENT_LIST_DIR}
)
```

## 4. IRQ table format

board_irq_map.h declares count + table symbol:

```c
#define NEXUS_BOARD_IRQ_COUNT 15
extern const nexus_irq_desc_t nexus_board_irq_table[NEXUS_BOARD_IRQ_COUNT];
```

board_irq_table.c defines each entry:

```c
{ .irq_n = <irq>, .name = "<NAME>", .domain = NEXUS_IRQ_DOMAIN_SECURE|NEXUS_IRQ_DOMAIN_NONSECURE, .priority = <prio>U }
```

Count and table length must remain in sync.

## 5. What to edit

Edit these files directly:

- bsp/<board>/config/memory_map.h
- bsp/<board>/config/linker_unified.ld
- bsp/<board>/config/board_irq_map.h
- bsp/<board>/config/board_irq_table.c

Also ensure board secure module includes the IRQ table source:

- bsp/<board>/CMakeLists.txt -> SOURCES includes config/board_irq_table.c

For private board internals, keep declarations in:

- bsp/<board>/inc/board_private.h

and add the directory only as a private include path for board implementation targets:

- bsp/<board>/CMakeLists.txt -> PRIVATE_INCLUDE_DIRS includes ${CMAKE_CURRENT_SOURCE_DIR}/inc

## 6. Migration notes from old docs

If you previously used board_resources.cmake and template files:

- Remove board_resources.cmake include from <board>.cmake
- Remove .in template usage for IRQ files
- Keep equivalent values, but store them directly in manual files

## 7. Quick checklist after edits

1. Update memory map and/or IRQ table files.
2. Verify NEXUS_BOARD_IRQ_COUNT matches table entry count.
3. Build the selected board.
4. Check board early init behavior for expected IRQ domain and priority policy.
